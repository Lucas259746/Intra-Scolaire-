Présentation du projet

Problème

  • Outils numériques fragmentés
  • Communications sur plusieurs canaux non reliés
  • Aucune vue centralisée pour l'établissement
  • Saisies redondantes entre logiciels

Solution

  • Intranet scolaire unifié
  • Gestion pédagogique & administrative centralisée
  • Système multi-rôles (Admin, Formateur, Étudiant, Visiteur)
  • Conforme RGPD & accessible RGAA

Authentification & Sécurité

Connexion

  • Login / mot de passe hashé (bcrypt)
  • Inscription publique sur /register
  • Validation email obligatoire à l'inscription (format html5)
  • Protection CSRF sur tous les formulaires
  • Rate limiting : 3 tentatives max / 30 min
  • Rôle & promotion assignés par l'admin

Qui fait quoi ?

Étudiant Se connecte, gère son profil
Formateur Se connecte, gère son profil
Visiteur Se connecte, accès lecture seule sur les cours , les absences
Admin Crée les comptes, attribue les rôles

Changement de rôle sécurisé AdminController.php

#[IsGranted('ROLE_ADMIN')]
public function setRole(Request $request, User $user, ...): Response
{
    $allowedRoles = ['ROLE_STUDENT', 'ROLE_TEACHER', 'ROLE_ADMIN', 'ROLE_VISITOR'];
    $role = $request->getPayload()->getString('role');
    if (!in_array($role, $allowedRoles, true)) {
        throw $this->createNotFoundException('Rôle invalide.');
    }
    $user->setRoles([$role]);
    $em->flush();
}
